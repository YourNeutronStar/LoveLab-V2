# Changelog

## 2.0.0 — LoveLab Studio themes and languages

- Refactored monolithic HTML into maintainable editor HTML, editor CSS, translations, story presets, application logic, and standalone story source files.
- Added cute CSS bear-and-panda, galactic alien, and floral visual themes.
- Added three full story presets to match the new themes (6 total presets; themes independently selectable).
- Added Turkish, English and German editor localization, system prompts, and corresponding preset stories.
- Kept portable, single-file HTML export and editable JSON backups.
- Preserved choices, branching, runaway button, local saving, preview, fullscreen, and URL-fragment sharing.
- Added build script, README, developer guide and QA checklist.
- Kept the old browser-storage key as a read-only migration fallback.
